# SVG-контуры для нижнего дисплея

Общий образ физического прибора и его экранов задан в
[визуальном стиле инопланетного ручного сканера](alien-hand-scanner-visual-style.md).
Этот файл описывает только технический контракт контуров для нижнего дисплея.

Для редактирования формы всех физических экранных зон используйте
`full-display-zones-template.svg`. Его `viewBox="0 0 1286 745"` и пути с
идентификаторами `left-zone`, `center-zone`, `bottom-zone`, `hint-zone-1…3`
точно соответствуют `display/DisplayGeometry.kt`. После изменения зон передайте
SVG разработчикам: координаты из него нужно перенести в Kotlin-код.

## Как работать с шаблоном

1. Откройте `bottom-status-outline-template.svg` в Figma, Illustrator или
   Inkscape.
2. Не изменяйте внешнюю янтарную форму: это точная геометрия нижней зоны
   дисплея.
3. Нарисуйте внутри неё один открытый векторный контур объекта.
4. Не масштабируйте и не переводите координаты вручную.
5. Передайте исходный редактируемый файл и итоговый SVG.

## Итоговый SVG

- Оставьте тот же артборд: `viewBox="0 0 640 200"`. Приложение проецирует эти
  координаты напрямую на физическую нижнюю зону, поэтому пересчёт не нужен.
- Удалите фон и внешнюю форму шаблона перед экспортом.
- В итоговом файле должен остаться один видимый путь с `id="outline"`.
- Путь должен быть открытым: не замыкайте его в фигуру.
- Не добавляйте текст, растровые изображения, фон, рамку, заливку, тени или
  визуальные эффекты.
- Сохраните файл в UTF-8 SVG и назовите его строго по имени из каталога
  (`scan-outline-catalog.md`): идентификатор архетипа в нижнем регистре плюс
  `.svg`, например `cat.svg`, `mushroom.svg`, `pen_pencil.svg`.

Пример итогового файла:

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 640 200">
  <path id="outline" d="..." fill="none"/>
</svg>
```

Цвет, толщина линии, свечение и сама morph-анимация задаются приложением.

## Каталог

Полный список из 100 поддерживаемых `visual_id` и имён файлов —
`scan-outline-catalog.md`. Файлы, которых ещё нет в `app/src/main/assets/scan_outlines/`,
приложение безопасно заменяет контуром `UNKNOWN_OBJECT`, а при его отсутствии —
процедурным фолбэком, поэтому контуры можно поставлять по одному.
