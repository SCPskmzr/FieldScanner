# Документация FieldScanner

Это описание **реализованного состояния** приложения. Код остаётся окончательным источником истины; документация объясняет назначение, экран, поток и ограничения модуля.

## Философия продукта

Пользователь приложения — ребёнок, которому не обязательно уметь читать, чтобы им пользоваться. Поэтому в обычной (non-debug) сборке интерфейс не показывает ребёнку никакого текста — ни заголовков, ни координат, ни имени контакта, ни номера телефона. Смысл экрана передаётся только цветом, иконкой, фото и анимацией. Текстовый вывод допустим исключительно под `BuildConfig.DEBUG`. Статус решения и известные расхождения с текущим кодом — `docs/agent-memory/decisions.md` («No visible text for children»); план приведения кода в соответствие — `docs/tasks/TASK-002-no-visible-text-for-children.md`.

## Экраны и режимы

`MainActivity` — единственный Activity и переключает следующие режимы:

1. Неактивный сканер — центральное табло и подсказки рун.
2. Камера — полноэкранный rear-camera preview; можно снять фото или выйти.
3. Проверка фото — сделанное фото с действиями «переснять» и «использовать».
4. Анализ — ожидание удалённого анализа; его можно отменить.
5. Журнал — просмотр сохранённых находок, переходы, воспроизведение аудио и голосовой поиск.
6. Контакты — выбор разрешённого контакта и инициирование звонка.
7. Входящий/активный звонок — специальное состояние поверх обычного экрана; управляется Android Telecom.

Подробные переходы и доступные руны находятся в [UI и вводе](modules/ui-and-input.md).

## Как поддерживать актуальность

Для кода каждого модуля указана соответствующая страница. При выполнении задачи агент обязан проанализировать diff и сам обновить summary модуля: поведение, экраны, состояния, ограничения и проверки. `scripts/check-documentation.ps1` и `scripts/check-documentation` проверяют, что соответствующая страница действительно изменилась в том же изменении; они не оценивают смысл текста.
