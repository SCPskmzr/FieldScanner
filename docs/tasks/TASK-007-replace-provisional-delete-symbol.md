# TASK-007 — Заменить временный символ удаления утверждённым дизайном

## Goal

Заменить временный символ мусорной корзины в состоянии подтверждения удаления
на утверждённый визуальный дизайн.

## Context

TASK-006 вводит отдельное безтекстовое состояние подтверждения удаления в
журнале. До утверждения визуального языка приложения в нижнем сегменте
используется временный символ мусорной корзины.

## Requirements

- Получить или использовать утверждённый дизайн символа подтверждения
  удаления.
- Заменить только временную корзину в нижнем сегменте состояния удаления.
- Сохранить отсутствие читаемого текста и два доступных действия: подтвердить
  либо отменить.
- Не менять логику удаления, выбор рун или навигацию журнала.

## Acceptance criteria

- [ ] В состоянии подтверждения удаления используется утверждённый дизайн,
  а не временная корзина.
- [ ] Нижний сегмент и действия рун остаются понятными без чтения.
- [ ] Подтверждение и отмена сохраняют поведение, определённое в TASK-006.

## Out of scope

- Создание или утверждение дизайна: это входное условие задачи.
- Изменение сценария удаления либо модели данных журнала.
- Редизайн остальных состояний нижнего сегмента.

## Relevant areas

Компоненты отображения нижнего сегмента, ресурсы визуальных символов,
`ScannerScreenCoordinator.kt`, документация UI.

## Verification

- [ ] `./scripts/verify-and-install.ps1` на Windows (или с `-Target emulator`)
  либо `./scripts/verify` на Linux/macOS/CI.
- [ ] Acceptance criteria checked.
- [ ] Вручную на устройстве: открыть журнал, войти в подтверждение удаления и
  проверить утверждённый символ, отмену и подтверждение без появления текста.
