# TASK-006 — Убрать текст из подтверждения удаления фото в журнале

## Goal

Удаление фотографии из журнала не показывает ребёнку читаемый текст.

## Context

В журнале руна Flux открывает системный `AlertDialog` с заголовком, пояснением и
текстовыми кнопками. Это нарушает правило интерфейса без текста для ребёнка,
хотя удаление остаётся необратимой операцией и требует подтверждения.

## Requirements

- После нажатия Flux в журнале переводить приложение в отдельное состояние
  подтверждения удаления.
- В этом состоянии нижний сегмент показывает символ мусорной корзины, без
  читаемых слов или чисел.
- Оставить доступными ровно две руны: одну для подтверждения удаления и одну
  для отмены; их визуальная роль должна быть различима без чтения.
- Сохранить явный шаг подтверждения перед удалением; нажатие Flux не должно
  удалять запись сразу.
- Не менять удаление из Room и внутренних файлов, навигацию журнала или
  привязки остальных рун.
- Добавить или обновить unit-тесты для изменённой логики, если она выносится из
  Android UI.

## Acceptance criteria

- [x] При удалении записи из журнала на экране нет читаемого текста (включая
  заголовок, описание и подписи действий).
- [x] После нажатия Flux приложение переходит в состояние подтверждения, где
  нижний сегмент показывает символ мусорной корзины.
- [x] В состоянии подтверждения активны ровно две руны: подтверждение и
  отмена; пользователь может различить их и выполнить действие без чтения.
- [x] Подтверждённое удаление удаляет текущую запись и её медиафайлы; отмена
  возвращает к прежней записи без изменения журнала.
- [x] После удаления журнал показывает следующую доступную запись либо
  возвращается к неактивной камере, если записей не осталось.

## Out of scope

- Удаление находки с экрана результата анализа.
- Переработка остальных текстовых Toast-уведомлений и диалогов.
- Изменение модели данных, Room-схемы или формата медиафайлов.
